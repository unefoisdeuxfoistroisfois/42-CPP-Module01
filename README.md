# C++ - Module 01

## Allocation mémoire, pointeurs vers membres, références et switch

---

## Notions

- **new / delete** — allocation et libération sur le heap
- **Références** — alias vers une variable, différence avec les pointeurs
- **Filestreams** — lire et écrire des fichiers avec ifstream/ofstream
- **Pointeurs vers fonctions membres** — appeler des méthodes via des pointeurs
- **switch** — avec fallthrough intentionnel
